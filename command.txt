
1. For generate global url:
   ssh -p 443 -R0:127.0.0.1:5001 tcp@a.pinggy.io

2. Start Receiver:
   py receiver.py --port 5001

3. Generate Windows Sender EXE:
   py -m PyInstaller --onefile --clean --name sender sender.py

4. Generate Windows Receiver EXE:
   py -m PyInstaller --onefile --clean --name receiver receiver.py

5. Run on macOS (Double-Click):
   run_sender.command (or bash run_sender.command)
   run_receiver.command (or bash run_receiver.command)

6. Build Mac Standalone Executable (on a Mac):
   bash build_mac.sh
